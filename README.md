# 🏨 Hotel Reservation System

## 📋 گزارش مرحله اول: افزودن دو قابلیت جدید

## ✨ قابلیت‌های اضافه شده

### 1️⃣ 📱 ارسال پیامک (SMS)

#### تغییرات انجام شده:
- 🔄 **تغییر نام متد در اینترفیس MessageSender به sendMessage**
- 🔄 **تغییر نام متد در کلاس EmailSender مطابق با اینترفیس**
- ➕ **افزودن کلاس جدید SmsSender در پکیج service**
- 🔧 **اصلاحات انجام شده در کلاس ReservationService**:
  - ایجاد case جدید برای تشخیص روش ارسال پیام به صورت پویا

### 2️⃣ 💳 سرویس پرداخت جدید

#### تغییرات انجام شده:
- ➕ **افزودن متد پرداخت حضوری با نام payOnSite در PaymentProcessor**
- 🔧 **ایجاد case جدید در ReservationService برای پشتیبانی از نوع پرداخت جدید**
